Contributing to Aspen
=====================

Thank you for your intention to contribute to Aspen. As an open source community, we highly appreciate contributions to our project.

To make the process smooth for the project *committers* (those who review and accept changes) and *contributors* (those who propose new changes via pull requests), there are a few rules to follow.

## Contribution Guidelines

We use GitHub Issues and Pull Requests for tracking contributions. We
expect participants to adhere to the GitHub Community Guidelines (found
at <https://docs.github.com/en/site-policy/github-terms/github-community-guidelines>).

Please note that your contributions will be under the [Apache License 2.0](LICENSE).

### Get Involved

The Aspen project is developed by volunteers and is always looking for new contributors to work on all parts of the project.
Every contribution is welcome and needed to make it better. A contribution can be anything from a small documentation typo fix to a new feature. Better estimates for the figures used in the model (see [METHODOLOGY.md](METHODOLOGY.md)) are particularly valuable. We especially welcome contributions from first-time users.

#### Questions

Feel free to open an [issue](https://github.com/DigitalPebble/aspen/issues) to ask any questions you might have when planning your first contribution.

### Making a Contribution

- Create a new [issue](https://github.com/DigitalPebble/aspen/issues) on GitHub. Please describe the problem or improvement in the body of the issue.
- Next, create a pull request in GitHub. Before submitting it, check that `cargo clippy --all-targets -- -Dwarnings` and `cargo test` pass, as they are run by the CI.

Contributors who have a history of successful participation are invited to join the project as a committer.
